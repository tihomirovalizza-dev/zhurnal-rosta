# Журнал роста

Сайт-приложение без сборки и зависимостей. Записи хранятся на устройстве и синхронизируются через Supabase.

## Подключение Supabase

1. Создать проект на supabase.com.
2. В SQL Editor выполнить `supabase-schema.sql`.
3. В Authentication создать своего пользователя (почта и пароль) и отключить регистрацию новых пользователей.
4. В `config.js` вписать адрес проекта и публичный ключ (anon или publishable). Секретный ключ (service_role или secret) сюда вписывать нельзя.

## Размещение

Нужен любой статический хостинг с HTTPS, например GitHub Pages. На него выкладывается содержимое этой папки. `supabase-schema.sql` и `README.md` приложению не нужны.

После изменения файлов приложения нужно увеличить номер `CACHE` в `sw.js`, если меняется список файлов. Обычные правки подтягиваются при следующем запуске.
